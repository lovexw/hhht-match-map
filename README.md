# 青城有你 · 呼和浩特同城相亲地图

呼和浩特本地同城相亲网站的核心功能演示：以真实地图为载体，按新城区、赛罕区、回民区、玉泉区展示身边的单身用户，配套会员付费解锁、心动互动、筛选卡片与运营管理后台。全部数据为前端模拟数据，用于产品演示与后期立项参考。

## 在线演示

- 用户端相亲地图：`https://hhht-match-map.pages.dev/`
- 运营管理后台：`https://hhht-match-map.pages.dev/admin.html`

## 功能一览

### 用户端 `index.html`

- 真实地图：Leaflet 加载高德中文底图，支持标准 / 卫星图切换、缩放平移与定位
- 真实行政边界：DataV 行政区划数据裁剪出的四区多边形，点击区域名称直接飞往该区
- 60 位单身用户：男女各 30 位，按真实城区多边形拒绝采样落位，标记展示性别、在线状态、VIP 角标与心动数
- 游客模糊模式：未付费时头像与照片模糊、精确位置打码，点击标记弹出开通引导
- 模拟支付开通：月卡 39.9 / 季卡 99 / 年卡 199 / 终身 399，微信、支付宝二选一，点击即模拟支付成功并解锁全部资料（纯前端演示，不产生真实扣款）
- 心动互动：点击心动，该用户心动值即时 +1，本地记录心动列表，并有概率触发互相心动提示
- 多维筛选：性别、区域、年龄、身高、学历、婚姻、仅在线、仅认证、关键词搜索
- 卡片视图：地图 / 卡片双视图切换，卡片含照片、标签、职业、最近活跃与心动按钮
- 详情抽屉：约 40 个字段的完整资料，含照片、择偶要求、基本信息、认证与会员状态
- 点聚合：缩放时自动聚合点位，密集区域展示数量

### 运营后台 `admin.html`

演示账号：`admin` / `hhht@123`

- 数据总览：8 张核心 KPI 卡片
- 10 张图表：30 天男女新增趋势、性别比例、区域分布、年龄段、学历、职业 TOP10、付费转化漏斗、一周 7×24 活跃热力、套餐占比、心动榜 TOP10
- 用户管理：60 位用户表格，支持搜索、筛选、分页、查看详情、冻结、推荐与 CSV 导出
- 相亲地图：热力图 / 用户点位双模式，叠加四区边界与各区人数、性别构成统计
- 会员订单：模拟订单列表，前台演示支付产生的订单会实时出现在订单页
- 运营设置：支付、审核、推荐等开关（演示态）

## 技术栈

纯静态站点，无构建步骤、无后端依赖：

- Leaflet 1.9.4 + leaflet.markercluster（点聚合）+ leaflet.heat（热力图）
- ECharts 5（后台图表）
- 高德地图免费瓦片（中文底图，无需 Key）
- 原生 HTML / CSS / JavaScript，数据存于 `window.HHHT_DATA`
- 会员状态、心动记录、后台登录态保存在浏览器 localStorage
- 坐标系：数据坐标为 WGS84，前端通过 eviltransform 算法转换为 GCJ-02 后上图，与高德底图对齐

## 本地运行

任意静态文件服务器即可，例如：

```bash
cd hhht-match-map
python3 -m http.server 8123
```

浏览器打开 `http://127.0.0.1:8123/index.html`，后台地址 `http://127.0.0.1:8123/admin.html`。

直接双击 html 文件打开也能运行，但部分浏览器对本地 `fetch` 有限制，建议使用本地服务器。

## 重新生成数据

```bash
python3 scripts/gen_data.py
```

固定随机种子，按四区真实边界采样坐标，重新生成 `assets/js/data.js`。

## 部署到 Cloudflare Pages

本项目是纯静态站点，任意静态托管均可：

```bash
# 方式一：Wrangler
wrangler pages deploy . --project-name=hhht-match-map

# 方式二：GitHub 连接
# Cloudflare 控制台 → Pages → 连接仓库 → 构建命令留空 → 输出目录填 /
```
